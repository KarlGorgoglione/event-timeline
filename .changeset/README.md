# Changesets

This folder holds [Changesets](https://github.com/changesets/changesets), used
to version and publish `@event-timeline/core` and `@event-timeline/react`.

Run `pnpm changeset` to record a change, `pnpm version-packages` to apply
pending changesets to package versions, and `pnpm release` to build and publish.
The `demo` app is private and ignored by versioning.
